# 📦 프롬프트 보관함 (Prompt Archive)

자주 쓰는 프롬프트를 효율적으로 저장·관리하고, 동적 변수 템플릿 및 OpenRouter API 기반 AI 평가/다듬기 샌드박스까지 이용할 수 있는 **슬레이트 그레이 Modern Dark 웹앱**입니다.

---

## 🚀 최초 1회 설정 및 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. `.env` 파일 설정
`.env.example`을 참고하여 프로젝트 루트에 `.env` 파일을 생성(또는 수정)하고 OpenRouter API 키를 입력하세요.

```env
OPENROUTER_API_KEY=여기에_키_입력
PORT=3000
```
- API 키 발급: https://openrouter.ai/settings/keys

### 3. 프로그램 실행
`start.bat` 파일을 더블클릭하세요.
- 서버(`server.js`)가 실행되고, 브라우저가 `http://localhost:3000`으로 자동 오픈됩니다.
- 수동 실행 시: `npm start`

## 🌟 처음 사용자를 위한 핵심 기능 가이드

### 1. 🧩 동적 변수 템플릿 (`{{변수명}}`)
- **사용법**: 프롬프트를 저장할 때 변수로 바꿀 부분에 `{{언어}}`, `{{주제}}`, `{{코드}}` 처럼 중괄호를 써서 입력하세요.
  - *예시*: `"다음 {{언어}} 코드를 {{목적}} 기준에 맞춰 리팩터링해줘."`
- **복사 방식**: 카드에 **`[⚡ 변수 채워 복사]`** 버튼이 생성됩니다. 클릭 후 팝업 모달에서 변수값만 입력하면, 완벽하게 치환된 최종 프롬프트가 1초 만에 클립보드에 복사됩니다.

### 2. ⭐ 즐겨찾기(Pin) 고정
- 카드 상단의 **⭐️ 별 아이콘**을 누르면 해당 프롬프트가 상단에 항상 고정(Pinned)됩니다.
- 자주 쓰는 TOP 프롬프트를 맨 위에 올려 두고 빠르게 사용해 보세요.

### 3. 🔍 실시간 키워드 검색 & 정렬
- **실시간 검색**: 상단 검색창에 키워드를 입력하는 즉시 제목, 카테고리, 본문 내용이 초고속 필터링됩니다.
- **정렬 옵션**: 우측 상단 드롭다운에서 **[⏱️ 최신순 / 🔥 자주 쓴 순 / 🔤 이름순]**으로 목록 정렬 방식을 자유롭게 변경할 수 있습니다.

### 4. 🔥 사용 횟수(Usage Count) 자동 누적 & 전체 초기화
- **사용 횟수 자동 누적**: **`[📋 복사하기]`** 또는 **`[⚡ 변수 채워 복사]`**를 누를 때마다 사용 횟수가 자동 누적되어 카드에 `🔥 X회 사용` 뱃지가 표기됩니다.
- **전체 초기화**: 상단 대시보드의 **`TOTAL EXECUTIONS`** 통계 카드 내에 있는 **`[🔄 초기화]`** 버튼을 누르면 모든 프롬프트의 사용 기록을 0회로 안전하게 리셋할 수 있습니다. (템플릿 변수나 프롬프트 내용은 안전하게 보존됩니다.)

### 5. ✨ AI 검토 샌드박스 & 예시 프롬프트 1-Click 저장
- **사용 방법**: 화면 오른쪽 아래 **`✨ AI 평가 & 샌드박스`** 버튼을 누르면 AI와 대화하며 프롬프트를 검토할 수 있습니다.
- **예시 프롬프트 저장**: AI가 답변해 준 내용 중 총평이나 설명 글을 제외하고 **`✏️ 예시` 파트의 실제 개선 프롬프트만 자동으로 정밀 추출**합니다.
- 답변 하단의 **`[📥 예시 프롬프트만 보관함에 저장하기]`** 버튼을 누르면, 완성형 프롬프트만 상단 등록 폼으로 깔끔하게 자동 입력됩니다.

### 6. 💾 JSON 데이터 백업(내보내기) & 스마트 가져오기(병합)
- **전체 내보내기**: 검색창 옆 **`💾 내보내기`** 버튼을 누르면 `promptarchive_backup_YYYY-MM-DD.json` 파일이 다운로드됩니다.
- **가져오기 & 병합 정책**: **`📥 가져오기`** 버튼으로 JSON 파일을 선택하면 확인 창이 열리며 4가지 충돌 처리 방식을 선택할 수 있습니다:
  1. **스마트 병합 (추천)**: 기존 데이터 유지 + 중복 ID는 파일 내용으로 갱신 + 신규 항목 추가
  2. **안전 병합 (새 ID)**: 중복 여부 상관없이 모든 항목에 새 ID를 부여하여 안전하게 전체 추가
  3. **중복 건너뛰기 (스킵)**: 기존에 없는 ID의 신규 항목만 추가
  4. **전체 덮어쓰기**: 기존 데이터를 모두 지우고 파일 데이터로 100% 교체

### 7. 🔗 카드별 단일 프롬프트 JSON 공유
- 카드 하단의 **`[🔗 공유]`** 버튼을 누르면 해당 프롬프트의 **제목, 카테고리, 프롬프트 내용 전체가 JSON 객체 형태로 클립보드에 복사**되어 다른 사람에게 메신저나 문서로 간편하게 전달할 수 있습니다.

## ⚙️ 상세 설정 변경 (고급)

### 1. AI 평가에 사용할 모델 우선순위 변경
`config/models.json`에서 시도할 OpenRouter 모델 목록과 순서를 변경할 수 있습니다.
```json
[
  "google/gemma-4-31b-it:free",
  "google/gemma-4-26b-a4b-it:free",
  "nvidia/nemotron-3-super-120b-a12b:free"
]
```
- 1순위 모델 실패 시 자동으로 다음 순위 무료 모델로 페일오버(Failover)됩니다.

### 2. AI 평가 규칙(System Prompt) 수정
`config/systemPrompt.txt` 파일을 수정하여 AI의 평가 톤앤매너나 응답 형식을 원하는 대로 커스텀할 수 있습니다.
